# GlobalTensor、LocalTensor 与 TPipe/TQue

本讲义为 MindOS 原创课程草稿，尚待教师审核。先理解现象与条件，再尝试完整例子。

## 为什么要学

核内计算与数据搬运并非同一件事。Ascend C 的局部张量和流水线框架帮助开发者在受限片上存储里组织搬入、计算、搬出，并在阶段之间传递数据。

## 核心原理

GlobalTensor 对应全局可访问数据视图，LocalTensor 表示片上局部缓冲。典型矢量算子把处理拆为 CopyIn、Compute、CopyOut：从全局搬入局部，调用计算 API，再写回全局。TPipe 管理流水线所需资源，TQue 在阶段间传递缓冲与同步；申请、入队、出队、释放的生命周期必须成对。双缓冲可用于重叠搬运与计算，但先证明单缓冲正确。

## 逐步例子

逐元素加法的一次 tile：先为两个输入各准备局部缓冲并搬入，再申请输出局部缓冲计算 `x+y`，最后把有效结果写回全局。若在 Compute 仍使用输入时就 FreeTensor，会造成数据生命周期错误；若遗漏 DeQue，阶段无法得到就绪数据。画出每个缓冲在三阶段的所有权，比直接堆 API 更稳妥。

## 常见误区与自查

不要把队列理解为普通数组，也不要认为 TPipe/TQue 会替你修复越界和错误 tiling。自查位置类型、队列深度、每次申请和释放、数据依赖顺序。

## 学完后的检验

先合上讲义，自己复述：这个方法解决什么问题、前提是什么、例子中的每一步为何成立、换一组输入时哪些判断必须重做。再完成两道不同的公开练习；练习表现只是初步证据，不能代替真实项目中的实现与复核。
