# MindOS

**创建自己的课程，一节一节学习。** 用户输入课程名称和可选目标，AI 先规划小节目录；讲解、追问和独立小测按当前小节生成。课程进度只有在用户点击“进入下一小节”时推进。

## 已实现

- 自定义课程：不预装课程。课程名称、目标和 AI 生成的小节目录保存在本机。
- 逐节教学：首次进入某节时生成讲解并保存；刷新后继续看原讲解，随时追问并保留本节对话。
- 独立小测：每次生成 4 道单选题，提交后保存题目、作答、得分和解释；可反复生成新题复测旧小节。
- 课程记忆：每节显示最近两次小测的正确率与暂定状态；后续讲解可参考同一课程的错题线索。课程显示已测小节覆盖率和已测小节的平均正确率。不同课程与浏览器会话的数据分开。
- 模型管理：网页添加兼容 Chat Completions 的 API 地址、模型名称和密钥；密钥在本机加密保存，不回显。

项目不再包含预设课程、课程包或外部 RAG 资料库。AI 生成的小节和题目未经教师审核；小测正确率只能作为学习线索，不能作为正式能力认证。

## 本机运行

需要 Python 3.10+：

```bash
python -m pip install -r requirements.txt
python -m mindos.server
```

打开 <http://127.0.0.1:8765>。先在“管理模型与 API”中配置并测试模型，再点“新建课程”。例如使用 DeepSeek 时，API 地址可填 `https://api.deepseek.com`，模型名称填 `deepseek-flash`，密钥只在本机网页输入。

学习数据默认保存在 `data/mindos-demo.sqlite3`，不会提交到仓库。旧版数据库首次由新版打开时，会在同目录生成 `mindos-demo.sqlite3.before-custom-courses.sqlite3` 备份，然后清除旧课程、旧题目和检索缓存；模型配置会保留。如果旧密钥在当前运行环境无法解密，重新输入并保存即可。

运行测试：

```bash
python -m unittest discover -s tests -v
```

## 边界

当前是仅监听本机的原型，浏览器 Cookie 用于区分学习空间，没有账号登录。不要把服务直接暴露到公网，也不要录入真实学生的敏感资料。模型服务可能收费；模型生成的课程顺序、知识讲解和题目答案需要学习者核对，正式教学还需要教师审核和真实学习效果验证。
