# 课程智能助教

页面右下角的 ✦ AI 是悬浮导师，有选定课程时提供该课程专属助教。点击可展开聊天，收起后仍可继续阅读；图标固定在可视区域，支持鼠标／触摸拖动，以及聚焦图标后 Alt + 方向键移动。位置按浏览器会话和课程保存在 SQLite，刷新或服务重启后读取；更小的窗口会把图标与聊天面板限制在可视范围内，不覆盖保存的桌面坐标。入口在各页面可见；驾驶舱与成长档案绑定所选课程，课程空间绑定当前小节和知识点。没有选定课程时引导选择课程，禁用发送并清空可见聊天，不混用上一门课的记忆。拖动结束会吸附到最近的屏幕边缘；未选课程时的位置仅保存在本机浏览器。

聊天独立于已有章节追问和知识点追问，保持原页面布局与学习流程。发送失败会保留输入并显示错误，不写入半条聊天；请求编号相同的重试不会重复保存。历史可加载更早记录，切换课程不会显示上一门课的对话。

## 回答流程

`CourseTutorService`：校验课程所有权 → 读取当前小节／知识点与学习记录 → 查找课程知识原子和前置关系 → 模型理解问题并规划解释策略 → 必要时检索公开资料 → 模型解释 → 校验关联知识点 → 原子性保存问答。

后端读取真实课程名称、目标、个人水平、课程难度、来源策略、已开放小节、当前讲解、知识点解释、原子测试状态、阅读记录、近期学习内容、关系与前置知识、最多三份资料中的选定结构块及来源冲突。浏览器只提交当前小节和知识点编号，不接受它伪造的正文或掌握率。语义规划可选择其他已开放知识点；只有当前课程中已开放且未弃用的原子可作为跳转链接。

默认用“简单理解 → 直观解释 → 深入说明 → 与当前课程关联”解释，模型按问题自动选择生活例子、数学直觉、设计原因或比较，不要求用户选择模式。首遇术语解释含义，依据实际用户水平调整难度。这里是提示词要求，教学准确性与可理解性仍需实际学习者评估，不是学习效果认证。

阅读和助教聊天不作为掌握证据；本服务不改课程进度、课程状态、图谱、知识原子、阅读事件或独立测试。未作答测试只提供问题和选项，不向模型传入答案或解析，要求助教讲思路而不泄露答案。用户主动点击关联知识点后走原有知识点入口，仍受小节开放规则约束。

## 联网边界

基础数学、已有课程概念通常直接结合课程和模型知识回答。最新论文、模型／软件版本、接口变化和新闻由模型判断是否搜索；明显的时效关键词会强制搜索，避免模型错误跳过。规划失败有本地保守策略，并记录规划警告；模型生成最终回答失败则返回错误供重试。

检索沿用当前课程 `search_mode` 与已加密保存的搜索配置。免密钥仅查 Wikipedia 与 GitHub，覆盖有限；Brave、Tavily 或兼容接口需已有配置。本模块只读取实际搜索标题与短摘要，不声称读过网页全文，不把搜索结果自动变成 SourceDocument 或知识图谱内容。回答旁展示真实结果链接和入口说明。

检索失败或无可用来源时，显示无法核实最新信息的提示，来源列表为空，模型只能解释稳定知识并明确不确定性；不会生成假来源。课程原文也是选定结构块，不代表读完整文件。来源冲突继续保留，不因为资料优先或助教回答而获得事实认证。

## 数据与接口

新增 `assistant_message`：id、user_id、course_id、role、content、knowledge_atom_id、created_time，并保存 exchange_id、提问时的章节／知识点上下文、合法关联知识和实际检索报告。问答成对保存，跨课程隔离；送往模型的聊天历史最多最近12条。

新增 `assistant_position`：id、user_id、course_id、position_x、position_y、updated_time。当前本机原型的 user_id 沿用浏览器会话所有权，没有额外账号系统。密钥不进入聊天接口或学习上下文。聊天记录保存在本机；问题、选定资料和学习上下文会发送给用户配置的模型。

| 操作 | 接口 | 内容 |
| --- | --- | --- |
| 提问 | POST `/api/courses/{id}/assistant/chat` | `{message, request_id?, current_context?:{section_ordinal,knowledge_atom_id?,atom_mode?}}` |
| 历史与位置 | GET `/api/courses/{id}/assistant/history` | 每页最近80条；`before=最早消息id` 加载更早记录 |
| 保存位置 | PUT `/api/courses/{id}/assistant/position` | `{x,y}`，像素坐标 |

回答返回 `answer`、`related_knowledge:[{id,title,section}]`、实际 `search` 报告和已保存的 `messages`。编号与链接由服务器匹配课程知识结构，不采用模型捏造的编号。

软删除保留助教历史和位置，但停止访问；恢复后仍保留。复制课程不复制助教聊天与位置。永久删除清理两个助教表的课程关联记录。

前端模块 `web/components/CourseAssistant/course-assistant.js` 内含 AssistantButton、AssistantPanel、ChatMessage、ChatInput、DraggableAssistant；通过页面可见状态和章节／知识点显示变化读取上下文，不改原有学习动作。后台接口采用注入式模型与搜索适配器，便于未来替换模型；主动提醒、主动练习与语音暂未实现。
