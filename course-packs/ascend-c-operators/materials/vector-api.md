# 矢量计算 API、类型与数值语义

这是从零开始的 MindOS 课程草稿，尚待教师审核。读不懂某个词时，先看下面的术语，再按步骤阅读；无需先会做题。

## 第 0 步：先认清本讲的词

- **矢量运算**：对一组元素执行相同计算。
- **数值精度**：有限位数表示实数时产生的误差性质。
- **dtype**：元素的数据类型，影响范围与精度。

## 第 1 步：从一个问题出发

逐元素加减乘除、比较和归约等操作都要匹配具体 API 的输入类型与数据布局。知道数学式子还不够，必须确认目标平台支持的精度、对齐和计算语义。

## 第 2 步：理解它怎样工作

先按算子契约选择支持的矢量或高阶 API，再核对每个 API 对输入输出 dtype、shape、重复次数和掩码的要求。fp16、fp32 等浮点类型的舍入与溢出行为不同，计算顺序变化也可能带来误差。归约比逐元素运算更依赖跨块合并策略；无效尾部数据不可进入结果。

## 第 3 步：跟着例子做

要计算 `z=x+y`，先检查两个输入张量的类型与布局是否匹配，再用官方 Add 相关接口处理一个有效 tile。若最后仅 6 个有效元素，不可把填充位计算结果当作真实输出。把 CPU 参考的逐项结果按指定绝对或相对容差比较，并分别检查正负数、零和较大值。

### 1. 先算数学结果

逐元素加法 x=[1,2]、y=[3,4] 的数学结果是 [4,6]。设备 API 的选择还必须匹配输入 dtype、有效长度和目标内存位置，不能只看函数名像“加法”。

### 2. 再查数值差异

fp16 等有限精度类型不能精确表示所有实数。逐元素结果与高精度参考可能有小误差；应按题目允许的绝对或相对容差比较，并覆盖极值和尾块。

## 常见误区与自查

不要以“看起来接近”代替正式精度标准，也不要跨数据类型复用未经核对的向量指令参数。自查 dtype、有效长度、对齐、溢出和误差度量。
