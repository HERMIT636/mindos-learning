# 标准点积：从分量计算到方向关系

本讲义为 MindOS 原创公开教学材料，内容状态：待教师／助教审核。先修：二维实向量的分量、加法和长度。

## 点积要回答什么问题

向量 (x, y) 表示二维方向和大小。我们已经能把两个向量相加；现在想得到一个**数**，用来描述它们在方向上有多一致。二维实向量的标准点积为：如果 a = (a₁, a₂)、b = (b₁, b₂)，那么 a · b = a₁b₁ + a₂b₂。按相同位置配对、相乘、再求和；结果是标量，不是新的二维向量。

## 从计算步骤理解公式

取 a = (2, 1)，b = (3, 5)。第一分量配对：2 × 3 = 6；第二分量配对：1 × 5 = 5；最后相加，a · b = 11。写草稿时把“配对”和“求和”分成两步，便于发现把第二个向量分量看反、漏掉负号等错误。

再看 a = (2, -1)、b = (3, 4)：a · b = 2 × 3 + (-1) × 4 = 2。负号不能丢；公式中两个乘积可能互相抵消。仅仅把分量分别相乘得到 (6, -4)，还没有算完点积，因为那是一个二元组，不是最终的数。

## 为什么点积能联系“方向”

在标准欧氏平面中，两个非零向量还满足 a · b = |a||b|cosθ，其中 θ 是它们之间的夹角。这个式子说明：夹角小于 90° 时 cosθ 为正，点积为正；夹角等于 90° 时 cosθ 为 0，点积为 0；夹角大于 90° 时点积为负。

用一个容易看见的例子验证：水平向右的 (3, 0) 和竖直向上的 (0, 2) 垂直。按分量算，3 × 0 + 0 × 2 = 0。这里两个向量都不是零向量；“点积为 0”不等于“两个向量都是 0”。反过来，两个**非零**二维实向量的标准点积为 0，就说明它们垂直。必须说“非零”，因为零向量和任何向量的点积都是 0，但零向量没有可用来定义夹角的方向。

## 为什么分量公式会对应夹角

想进一步追问，可以看两个向量的差 a - b。按照长度公式展开，它的长度平方为 |a - b|² = (a₁ - b₁)² + (a₂ - b₂)² = |a|² + |b|² - 2(a₁b₁ + a₂b₂)。另一方面，把 a、b 和 a - b 看成三角形的三边，由余弦定理也有 |a - b|² = |a|² + |b|² - 2|a||b|cosθ。比较这两个表达式，相同的部分抵消，就得到 a₁b₁ + a₂b₂ = |a||b|cosθ。你暂时不必记住推导的每个符号，但应看到：**对应分量乘积之和并非凭空规定的方向指标**，它和熟悉的长度、夹角关系一致。

## 把几何关系算出来

设 a = (1, 2)、b = (2, -1)。先算 1 × 2 + 2 × (-1) = 0，再检查两者都不是零向量，于是可判断它们垂直。这里的分量既非全 0，也没有“每项乘积都为 0”，但正负两项相互抵消。这个例子提醒我们：只有**总和**是判断依据。

再取 a = (1, 0)、b = (-2, 1)，点积为 -2。负号表示夹角是钝角，但点积本身不是角度；不能把 -2 读成“-2 度”。若想进一步算角度，还需要两个向量的长度，并由 cosθ = (a · b)/(|a||b|) 推得。

## 常见误区与排错顺序

- 把点积当成逐分量乘后的向量：点积最后还要把乘积**相加**，输出一个数。
- 把 a₁ 与 b₂ 错配：先标出两个向量的第一、第二分量，再按同一位置配对。
- 以为点积为 0 必有一个零向量：不同方向的非零向量也可能垂直；乘积项还可能相互抵消。
- 不加条件地谈零向量“垂直于任何向量”：讨论夹角时需要两个非零向量；零向量没有确定方向。
- 忘记点积的正负与夹角有关，但点积数值还受向量长度影响：仅凭点积为 6，不能直接断言一个固定角度。

## 学完后能否自己解释

取 a = (4, 1)、b = (1, -2)。先逐项相乘：4 与 -2；再求和得 2，因此点积为正。请再用一句话解释“正”在这里对夹角意味着什么，同时说明为什么它不直接等于角度。若这一步还难，回到“长度与 cosθ 的关系”重看点积的几何意义。
