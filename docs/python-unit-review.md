## 资料与准确性

- 讲义明确区分 `def` 定义与带括号的调用、形参与实参、`print` 的输出与 `return` 的调用结果，并说明未执行 `return` 时返回 `None`。
- 语义核对依据：[Python 官方教程「定义函数」](https://docs.python.org/3/tutorial/controlflow.html#defining-functions)、[语言参考「return 语句」](https://docs.python.org/3/reference/simple_stmts.html#the-return-statement)、[内置函数 `print`](https://docs.python.org/3/library/functions.html#print)。
- 材料为原创入门示例，不含第三方教材全文；公开资源和练习仍需教师确认表述是否适合目标学生。

## 知识关系

当前图为「函数定义与调用 → 返回值」。它表示本单元的**教学先修顺序**：先知道如何调用函数，再讨论调用后得到什么值；并非声称所有 Python 函数都必须显式返回值。该图目前只有两节点、一条边，可用于小规模原型，但不足以刻画参数传递、控制流或副作用等更细的误解。后续扩展应先收集学生错误样本，再决定是否拆分节点。
