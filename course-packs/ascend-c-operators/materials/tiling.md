# Tiling、多核分块与尾块

本讲义为 MindOS 原创课程草稿，尚待教师审核。先理解现象与条件，再尝试完整例子。

## 为什么要学

输入尺寸常在运行时变化，芯片的片上缓冲区也有限。Tiling 把工作拆成可执行的核间与核内块，是连接数学问题和硬件资源的关键步骤。

## 核心原理

先定核数和每核处理区间，再定循环次数、块长度及末尾不足一块时的有效元素数。分块需满足片上存储容量、数据类型、对齐和 API 约束；不同算子还可能受归约依赖与布局影响。正确性优先：用小于一块、恰好整块、多一元素和非整除多核数四类输入检查覆盖。

## 逐步例子

N=1030、每块 256 个元素时，前 4 块覆盖 1024 项，余下 6 项必须单独处理或按允许方式填充并屏蔽无效项。若直接把第 5 块当 256 项读写，会越界。然后才比较不同块长对吞吐与片上缓冲占用的影响。

## 常见误区与自查

不要把“对齐后分配的物理空间”混同“逻辑有效元素”，也不要把调优得到的块长写死为所有形状的正确答案。自查每个 block 的 offset、valid length 和写回范围。

## 学完后的检验

先合上讲义，自己复述：这个方法解决什么问题、前提是什么、例子中的每一步为何成立、换一组输入时哪些判断必须重做。再完成两道不同的公开练习；练习表现只是初步证据，不能代替真实项目中的实现与复核。
