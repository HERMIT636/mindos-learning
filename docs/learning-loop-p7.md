# Learning Loop P7：知识宇宙可视化

P7 是已有知识和学习证据的只读展示层。入口为“个人知识档案 → 进入知识宇宙”。课程对应星系，小节对应星云，知识原子对应星辰，已有关系对应星轨。课程内原有 SVG 页面也统一了名称；章节顺序和推进规则保持不变。

## 数据与架构

`既有课程 / P0 证据 / P3 档案快照 / P4 任务 → KnowledgeUniverseAdapter → UniverseGraph → 二维 Canvas 与可访问列表 → 星辰选择 → 既有 P6/P6.5 导师`

新增 `mindos/universe`：适配器使用单独的 SQLite `mode=ro`、`query_only` 连接和一致性读取事务。没有新增数据库表，没有执行资料发现、知识生产、档案重建、校准计算或成长规划。P0–P6.5 的 68 个算法、协议和 Prompt 文件与 `6ef9ff3` 一致，详见 [冻结清单](learning-loop-p7-frozen.json)。

- P0 是当前星光的依据；接触或阅读只能显示学习中，不证明掌握。理解、应用、迁移和延迟记忆只有已测维度才展示。
- `mastery_state` 是展示字段，不写回 KnowledgeState。`stable` 表示已有延迟回忆及已测表现较稳，读取 P0 原有阈值；只有 P0 的完整掌握证据才显示 `mastered`。时间风险复用原有纯遗忘投影，不改历史记录或成绩。
- 星辰大小依据已有前置关系连接数；亮度是类别的透明度，不是内部掌握数值。没有知识分数或用户排名。补强与回忆提醒用中性虚线，不使用情绪颜色或“失败”评价。
- 星轨只转换已存关系，保留原类型及别名，不创造跨课程关系或把连接当事实认证。关系说明只解释类型，不编造连接理由。
- P3 只引用已存档案快照，检查原有映射指纹；失效或未建立的映射不展示，不触发重建。过大关联的历史快照不加载。本课仍须自己的独立证据。
- P2 只显示已有独立选择题校准的历史对照提示，分策略版本读取；模型开放评分与样本不足不参与星光判断。
- P4 只读取已有有效路线中的当前或可开始任务，不创建推荐或自动启动学习。已探索轨迹来自真实学习/答题记录，以时间列表展示，不伪造图谱边。

## 接口与交互

| 接口 | 用途 |
| --- | --- |
| `GET /api/universe?offset=0` | 分批展示当前用户课程及实际学习位置 |
| `GET /api/universe?search=Attention` | 搜索已有课程、小节和知识点 |
| `GET /api/universe/course/{course_id}` | 小节星云与章节聚合 |
| `GET /api/universe/course/{course_id}?chapter_id={id}&offset=0` | 当前小节的星辰及可见星轨 |
| `GET /api/universe/star/{star_id}?relation_offset=0` | 知识点、原有关系、独立记录和导师选择器 |

这些接口不支持写操作，检查课程所有权、回收站和分页参数。Star 编号编码课程及原子编号，同名或相同本地编号不会混用；未来小节只能查看结构，不能借探索解锁导师或学习。

页面提供三层视角、搜索定位、星轨解释、附近知识、当前学习位置及真实轨迹。地图支持缩放、拖动、双指手势、键盘和替代列表，保留减少动画设置。使用项目现有原生前端和二维 Canvas，不引入 React 构建、三维物理或粒子模拟。导师继续采用原有可拖动、可缩放、折叠窗口。

点击星辰只选择界面上下文。与 PRD 的示例传参不同，客户端只发送 P6 允许的课程、小节、知识点编号；后端重新获取真实状态、关系和误区，拒绝客户端提供掌握数据。选择时不调用原有 `openAtom` 的教学/阅读路径，也不触发候选观察核验。用户主动问答仍走原有导师记忆流程，独立检测仍走原有 P0 提交接口。

## 缓存与大图

策略版本 `universe-v1`：默认课程视角，每批最多 200 颗星辰、600 条可见星轨，课程/小节各 60 个。超过 200 时按已有章节聚合、分页；详情最多 40 条关联一批，搜索可定位当前批次以外的星辰。仅可见节点与关系返回前端，不一次获取全部原子。

图数据最多缓存 30 秒、24 个查询；手动刷新和星辰详情重新读取。课程编辑、新增、删除、完成、真实检测提交、阅读或规划变更清缓存，聊天不刷新图。导航与视口位置只存浏览器界面偏好。跨标签页/其他进程的变化不会实时推送，可手动刷新，重新进入或缓存到期后的下次查询会重新读取。

Canvas 使用按需绘制，没有持续后台模拟；重新切换地图会清理旧监听器和观察器。SQLite 原有图谱以 JSON 保存，大图仍需扫描现有 JSON，分页限制返回和绘制成本，并不宣称任意规模都能常数时间查询。

## 验证与复现

根目录与发布目录各通过 611 项测试（P7 新增 118 项），13 组浏览器检查及 1 个真实模型场景通过；68 个冻结文件 SHA 未变，290 个文件同步零差异。

实际自动测试、浏览器、真实模型、冻结和目录同步结果见 [验收报告](validation/learning-loop-p7-validation.json)。桌面 1440、手机 390 验证了档案入口、三层地图、星辰与导师、返回、刷新恢复、拖动缩放、双指手势、大图分页、关系解释和真实状态刷新。所有测试资料均为临时合成课程，个人学习数据库未改变。

真实模型通过星辰详情的选择器进入原有导师，收到 QKV 独立成功记录及 Attention 独立混淆记录；回答明确区分已有基础与继续练习的内容，见 [模型记录](validation/learning-loop-p7-model.json)。这只证明有限场景的实际运行，不证明普遍教学效果。
