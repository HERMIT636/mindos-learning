# 本地学习原型

这是用于大创／挑战杯项目开发和演示的本地预览版，课程内容仍标记为 `draft`。首次进入先选资料模式或大模型模式，然后选课程、带编号的章节与目标知识点。界面逐页推进：学前小测可做可跳过，随后从目标路线的第一讲逐步学到目标，再进入练习与自测，最后查看知识状态和后续计划。顶部步骤导航可在已解锁的功能之间跳转；所有状态都是工程规则的演示结果，不能当作真实学习效果。

## 启动

需要 Python 3.10 或以上版本。从仓库根目录运行：

```bash
python -m mindos.server
```

浏览器打开 <http://127.0.0.1:8765>。默认只监听本机地址 `127.0.0.1`。如需换端口，运行 `python -m mindos.server --port 8766`。使用 `python3` 的环境可相应替换命令。

不配置模型即可用资料模式学习五门草稿课程；机器学习、HPC 与 Ascend C 为主路线，Python 和线性代数是可选先修。讲解页沿先修路线逐讲展示，三门主课程的本地讲义包含术语解释、问题、规则、示例和小检查；开放式提问按关键词查找相关片段和出处。资料模式不会对新问题生成个性化解释或新题。服务端配置模型后，用户可选大模型模式：讲解请求包含当前诊断与独立作答状态，模型据此结合该知识点的多个资料片段讲解；页面仍附现有讲义供核对。模型还可回答疑问、分析用户自写的学习目标并按需生成一道练习小测验。模型输出仍可能有错，AI 小测验不计入掌握状态。单选和数值题由服务器按公开课程包中的答案判分。模式、目标、跳过状态、短诊断、作答和向量缓存保存在本地 SQLite `data/mindos-demo.sqlite3`，不会提交到 Git。不同浏览器会话用本地 Cookie 区分，**没有正式账号系统**，因此不要录入真实学生资料。

## 五分钟演示

1. 首次进入选“资料模式”，再进入“机器学习”；选第 1 章“问题与数据”中的“任务类型与基线”，点击“跳过测验，从零开始讲解”。
2. 阅读术语解释和逐步例子，用“下一讲”继续。遇到不懂的地方可提问；资料模式展示相关原文及出处，大模型模式生成补充解释。
3. 点击“继续：练习与自测”，先做辅助练习，再用另一道公开变式题独立复测。点击“查看证据与后续计划”，观察薄弱点、先修路线与状态更新。
4. 用顶部步骤导航回到知识点讲解或练习页，或者切换 HPC、昇腾 Ascend C；五门课程的数据和路线彼此隔离。

如已在服务端配置对话模型，可切换“大模型模式”，在目标框输入自己的描述并点击“分析并定位知识点”，确认建议后做或跳过学前小测。在资料助手中提问，或点击“生成一道小测验”；小测验的答案会在提交后给出，但不更新知识状态。三门主路线课程已按章节覆盖基础路径，但讲义仍为待教师审核的入门草稿；自定义目标超出当前知识点目录时应改选课程或补充课程包。

跳过学前小测不会记为答错或伪造诊断结果。短诊断仅给出起点标记，不计入独立掌握证据。辅助练习、同题求助和未自动评分的作答也不会计入。同一题多次提交至多提供一份当前证据。一次独立通过标记为“初步达标”，两道不同题通过标记为“复测通过”；一正一误标记为“待复核”。本地演示中的独立变式仍是公开示例题，不能用于正式效果研究。

## 可选模型与向量检索

把仓库根目录的 `.env.example` 复制为 `.env`，填写你选择的兼容服务的 API 地址、对话模型名称和可选的 Embedding 模型名称，然后**重启本地服务**。远程服务使用 HTTPS；本机服务可使用 HTTP。密钥只放在 `.env`，不要提交到仓库或输入页面。网页只让用户选择是否使用已经配置好的模型，不负责创建模型连接。模型模式下，自定义目标分析、讲解和小测验会向所配置服务发送课程目录、相关资料片段及演示学习状态；请仅用演示数据。

```text
MINDOS_MODEL_BASE_URL=https://api.openai.com/v1
MINDOS_CHAT_MODEL=你已开通的对话模型名称
MINDOS_EMBEDDING_MODEL=你已开通的向量模型名称
MINDOS_MODEL_API_KEY=你的密钥
```

只设置对话模型时，模型模式采用关键词检索后生成带原文入口的讲解；再设置 Embedding 模型时，系统计算课程片段和问题的向量并融合排序。资料模式问答与模型模式均可检索 `external-resources/curated/concept-guides.json` 中按知识点编写的十二则 MindOS 中文导读，并显示原始出处；机器学习与 Ascend C 的来源目录见 `external-resources/curated/source-index.json`。它们仍待教师审核，不等同于把下载的 HTML 或整本 PDF 自动切分、索引；无需下载原始文件也能运行原型。讲解提示词会把课程片段作为目标与依据，允许模型结合当前知识点及先修知识的诊断、独立作答证据补充直觉、推导和新例子；超出资料的重要补充须标为扩展说明，不冒充课程来源，也不用于独立判分。系统没有实时联网搜索。按需小测验仍限定在课程包片段范围内，不能凭模型自由扩展出题。资料模式不会请求对话或向量模型。向量缓存在本地 SQLite 中，缓存键包含模型、课程版本与资料内容。模型讲解连接失败时回到课程原文和关键词检索；自定义目标分析或小测验生成失败时显示错误，不伪装成 AI 结果。模型调用可能产生服务费用；请按服务提供方的政策使用资料。

接口采用 OpenAI 兼容的 [Chat Completions](https://developers.openai.com/api/reference/resources/chat) 与 [Embeddings](https://developers.openai.com/api/reference/resources/embeddings/methods/create) 请求格式。不同兼容服务对模型名称和功能的支持会有差异。本仓库不提供模型密钥，也不默认调用外部服务。

## 当前边界

- 固定资料讲解只来自当前课程包 `resources` 中的 Markdown；资料问答及模型问答、讲解另可引用经过选材的外部导读。参考答案和评分表不进入资料助手上下文。
- 仅对单选与数值题进行确定性评分；数值题目前要求与示例答案精确相等。简答与代码题不作自动评分，代码不会执行。
- “独立作答”使用公开示例题，答案在仓库里可查，仅供验证产品流程。本地另备未公开的独立测评草案，尚未接入应用，正式试点仍需教师审核与等值性试测。
- 状态规则没有经过教学效度验证；当前尚无正式登录、教师审核页、PostgreSQL / pgvector 部署和真实用户试点。
- AI 目标匹配和临时小测验只覆盖课程包列出的章节与知识点；模型输出需要学习者核对资料，未经教师审核不能用于正式评分。

运行检查：`python -m unittest discover -s tests -v`。课程格式检查仍使用 `python scripts/validate_course_packs.py`，后者需要先安装 `requirements-dev.txt`。
