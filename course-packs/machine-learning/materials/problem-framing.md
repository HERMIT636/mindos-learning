# 任务类型与基线

这是从零开始的 MindOS 课程草稿，尚待教师审核。读不懂某个词时，先看下面的术语，再按步骤阅读；无需先会做题。

## 第 0 步：先认清本讲的词

- **样本**：一条要观察或预测的记录，例如某一天的订单。
- **特征**：预测时已经知道、可以作为输入的信息。
- **目标**：希望预测的结果，例如下周订单数量。
- **基线**：最简单的参照做法；复杂模型至少应比它更有用。

## 第 1 步：从一个问题出发

做模型前先回答“输入是什么、要预测或发现什么、成功怎样衡量”。同一份数据可以形成不同任务：预测连续价格是回归，预测是否违约是分类，寻找没有标签的客户群是聚类。任务没定义清楚，后续再复杂的网络也可能优化错目标。

## 第 2 步：理解它怎样工作

监督学习用带目标值的样本学习输入到目标的映射；无监督学习从未标注数据寻找结构。先固定预测时可获得的特征、预测时点、目标变量和评价指标，再建立简单基线。基线可用多数类、均值或一条业务规则，它是后续模型是否真的有收益的参照。

## 第 3 步：跟着例子做

假设要在周一预测下周订单量。先列出周一已知的历史订单、节假日与促销计划；下周实际订单不能成为输入。目标是一个非负数，因此先按回归设计。用“上周同日订单量”作基线，记录平均绝对误差，再尝试更复杂模型。若模型只在训练集好看但测试集不超过基线，应先检查问题定义和数据。

### 1. 先定时间

我们要在周一晚上作预测。把“周一晚上”画成一条界线：界线左边已经发生、已知的信息可以用；右边还没发生的实际销量不能用。这样做是为了避免模型偷看答案。

### 2. 写清一条样本

把某个商品的某一周作为一条样本。输入可以写成“上周销量=100、下周有促销=是”；目标写成“下周实际销量”。在训练历史周的数据时，目标已知；真正预测新一周时，目标未知。

### 3. 先做不会学习的基线

假设三周的真实销量分别是 90、120、110，而“直接用上周销量”给出的预测是 100、100、100。三个绝对误差依次为 10、20、10，平均绝对误差是 (10+20+10)/3≈13.3。之后训练的模型要在同样的数据划分和指标下比较，才知道是否有改进。

### 4. 再决定模型类型

目标是订单数量，是数值，所以这是回归。若目标改成“下周是否缺货”，结果只有“是/否”，才是分类。问题定义先于选算法。

## 常见误区与自查

不要把有标签的数据一概叫分类，也不要把模型准确率当作所有任务的成功标准。自查时写一张任务卡：样本单位、预测时点、可用特征、目标、基线和误差代价；如果任何一项含糊，就先补齐问题定义。

## 自己试一试

预测下周订单时，把“下周实际订单”放进输入会怎样？先指出它在预测当时能否知道。

先不用急着做正式练习。能用自己的话说清这道小检查，才进入下一讲；答不出来就回到第 2、3 步。后面的公开练习只提供初步证据，不能代替真实项目中的实现与复核。
