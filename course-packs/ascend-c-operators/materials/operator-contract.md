# 算子数学定义与输入输出契约

这是从零开始的 MindOS 课程草稿，尚待教师审核。读不懂某个词时，先看下面的术语，再按步骤阅读；无需先会做题。

## 第 0 步：先认清本讲的词

- **算子**：把输入张量按规则变成输出张量的计算单元。
- **张量**：带形状和数据类型的多维数据。
- **shape**：各个维度有多长。
- **dtype**：元素的数据类型，例如浮点数。

## 第 1 步：从一个问题出发

算子赛第一步不是写核函数，而是把题目转成可验证的计算契约。公式、形状、数据类型、布局、广播、边界和误差标准若有一项理解错，即使代码很快也不算正确。

## 第 2 步：理解它怎样工作

先写纯数学或 CPU 参考实现，列出每个输入的 shape、dtype、取值范围和输出约束。区分逐元素、归约、矩阵类与变形类算子，因为它们的数据依赖和并行分块方式不同。确认是否允许就地写入、是否有动态形状、输出要按什么容差比对；题目规定优先于通用经验。

## 第 3 步：跟着例子做

以逐元素 Add 为例，若两个长度为 N 的张量形状相同，结果第 i 项为 `x[i]+y[i]`。先确认 N=0 或不能整除块长时如何处理、是否支持 fp16 与 fp32、输出是否允许和输入别名。用小尺寸手算例子与 CPU 参考结果一致后，再设计核函数；不要从某个示例代码反推正式题意。

### 1. 把题意写成数学规则

先只看逐元素加法：输入 x=[1,2,3]、y=[4,5,6]，输出应为 z=[5,7,9]，因为 z[0]=1+4、z[1]=2+5、z[2]=3+6。此时还不用懂 AI Core。

### 2. 写清输入输出边界

规定两个输入的长度都是 N、类型相同，输出也有 N 个元素。若长度不相等，不能擅自按广播处理；题目没有允许的行为，应先确认而不是猜。

### 3. 列出要测的情况

除了 N=3，还要测 N=1、不能整除拟定块长的 N、负数、小数和题目允许的 dtype。N=0 是否有效、误差容限是多少，都由实际赛题决定。

### 4. 先有慢而清楚的参考结果

用简单的 CPU 循环逐项相加，保存参考输出。未来写 Ascend C 后，同一输入分别运行参考实现和设备实现，逐项比较；只有正确后才谈分块和提速。

## 常见误区与自查

最常见错误是把样例形状当作全部形状，或忽略负数、非整块尾部和 dtype 转换。自查一张契约表：输入、输出、形状、精度、边界、判分口径。
