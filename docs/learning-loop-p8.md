# Learning Loop P8：多模态知识原子学习材料

基线：5ceba62；审计与实现日期：2026-10-04。资源是辅助学习材料，不是新的知识原子、评分或学习证据。

## 使用

更新依赖并重启服务。进入「个人知识档案 → 知识宇宙」，选择课程、章节和星辰，进入完整知识空间。总览引用现有知识状态；其他页签随实际材料出现。可添加笔记、公式、代码、图示、参考链接、实践说明，上传 PNG/JPEG、UTF-8 TXT/Markdown、PDF。普通界面使用表单，不要求填写 JSON。

- 公式使用本地 KaTeX 0.16.22 的 MathML 输出和浏览器排版，支持符号说明；复杂表达式无法排版时保留原文字。库与 MIT 许可在 `web/vendor/`，不依赖远程字体或 CDN。
- 代码安全高亮、复制，不执行。图示复用原有 SVG 结构，图片和图示可平移、放大、缩小、重置。
- 图片只支持静态 PNG/JPEG，Pillow 检查格式、尺寸、完整性并实际解码。上限 10 MB、1600 万像素。导师仅使用用户填写的替代文字和说明，当前没有图像识别。
- PDF 上限 30 MB。原文件保存为 `reference` 容器；选页生成独立 `paper_excerpt`，每次最多 12 页、3 万字。容器不会自动发送正文，失败会保留原文件供重试或删除。扫描 PDF 不做 OCR。
- 文字上限 5 MB。原文件完整保留；展示内容最多 3 万字，超出时保留截断标记和原文件入口；导师摘要预算更小。
- 参考链接不是正文。检索复用现有公开资料/Brave/Tavily，结果由用户确认关联；主动获取实际静态网页正文后才保存派生片段。检索覆盖和内容边界仍由原入口说明，不宣称全网搜索或阅读全文。
- 图示、例子、公式解释、代码、摘要按用户点击生成，不批量生成全课程。生成资源标记模型、时间、上下文指纹、待核对。摘要保留原文和派生关系。课程内容变化会使生成材料需要核对，用户资料不自动失效。

## 架构与协议

`mindos/resources` 独立资源层，`knowledge_resources` 存所有权、类型、来源、状态、SHA 和 metadata；`atom_resource_mappings` 存课程与原子关联、用途。资源内容保存在 metadata.payload；本地原文件位于数据库同级 `resources/`。文件名只使用资源 ID；不返回实际文件路径。关联支持多对多，不增加图谱边、不重建个人知识状态。

八种类型：text、formula、code、image、diagram、paper_excerpt、reference、practice。五种来源：generated、user_uploaded、course_content、external_reference、manual。公开参考链接经确认新增时是手动关联；获取真实网页片段标记 external_reference。

API：

| 操作 | 接口 |
|---|---|
| 原子资料列表/手动创建 | GET/POST `/api/courses/{course}/atoms/{atom}/resources` |
| 筛选与分页 | `offset/search/type`；每页默认 8 条 |
| 上传 | POST `/api/resources/upload`（JSON base64） |
| 详情/删除 | GET/DELETE `/api/resources/{id}`；删除必须 `confirm:true` |
| 原文件 | GET `/api/resources/{id}/file`；相同用户、固定目录与格式检查 |
| 选页/重新处理 | POST `/api/resources/{id}/extract` 或 `/reprocess`，`pages:[1,2]` |
| 实际网页片段 | POST `/api/resources/{id}/fetch`；复用已有公开网页获取及 SSRF 规则 |
| 关联/解除 | POST/DELETE `/api/courses/{course}/atoms/{atom}/resources/{id}/link` |
| 按需生成/摘要 | POST `…/resources/generate`，`type`，摘要需 `source_resource_id` |
| 材料问答 | POST `/api/resources/tutor/chat`；原 P6 选择器加 `focused_resource_id/resource_grounded` |
| 调试 | GET `/api/resources/{id}/inspect`，仅 MINDOS_DEBUG_LEARNING=1 |

未来章节、弃用原子、其他用户资源不可关联或提问。查看资源、浏览星图、上传或生成材料均不改变掌握、章节推进、成长任务完成状态。

## 导师与原系统协作

ResourceTutorService → 原 QualityTutorService → 原 TutorService/Context/ATIE → ResourceAwareModel → 原 ModelGateway → 原 P6 协议及 P6.5 质量检查 → 原对话记忆。传输、密钥、超时没有第二套实现；格式、引用与教学质量合用最多两次调用。

服务端只取当前原子已关联材料，优先焦点、主要讲解、问题相关和近期资料，最多 4 份、每份 6000 字、合计 8000 字；完整请求最多 26000 字。失败资料与 PDF 容器不进入正文。引用必须指向本次实际资源，摘录必须是所发片段的连续原文，历史保留实际材料引用。省略的 observations/memories/related_atom_ids 仅补为空数组，不生成推断、记忆或关联。

「只根据材料」模式必须选择材料，剔除其他课程正文、历史回答、误区说明和跨课程内容，不调用搜索；不足必须明确说明。仅格式合法且通过原教学质量检查的回答才保存。解析失败并且模型也失败时，显示不保存的「无法读取」提示，不猜文件名中的知识。原提示记录与独立检测排除规则继续生效。

引用匹配、范围和质量检查是有限校验，不是独立事实认证，也不能证明任何回答完全没有常识补充。真实模型测试使用临时合成资料，不等于一般教学有效性证明。

## 生命周期与集成

软删除课程保留材料和关联，恢复可见。复制课程默认不复制个人笔记或上传资料；可共享非个人 generated 结构材料，原有课程复制继续重置学习状态。永久删除只清理该课程曾关联、无其他关联且无派生依赖的生成资源；不扫其他课程的未关联资源。永久删除资料先显示关联/派生数量，明确确认后删除全部关联；有派生材料时需先处理派生材料。文件及目录软链接、越界路径拒绝。

实践材料的按钮进入原 P2 独立实践；任务仍由原评估流程生成，阅读任务不算完成，提示标记/评分/校准边界不变。学习计时只在主动点击时调用原 P5，活动为 course_learning，不自动开始或写能力状态。

P0–P7 的 73 个核心文件 SHA 保持不变，涵盖原 68 文件和 P7 五个后端文件。只在 Storage migration、HTTP dispatch/课程生命周期、前端导航和导师请求边界增加接入。旧 ATIE 浏览器用例改为当前 P6 历史接口与动态块断言；测试模型补齐 example 块，不修改产品 ATIE 或质量算法。
