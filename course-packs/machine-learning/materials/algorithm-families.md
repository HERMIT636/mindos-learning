# 树模型、集成学习与无监督方法

本讲义为 MindOS 原创课程草稿，尚待教师审核。先理解现象与条件，再尝试完整例子。

## 为什么要学

线性模型只是一个起点。树能表示分段决策和交互，集成把多个模型组合，无监督方法则回答没有标签时如何探索结构。理解任务差异，才能避免“一个算法包打天下”。

## 核心原理

决策树通过特征条件递归划分样本；随机森林用多棵有差异的树聚合，梯度提升按序纠正已有模型的误差。聚类寻找相似样本分组，PCA 寻找保留较多方差的低维方向，它们的输出不是现成的真实标签。算法选择应比较基线、样本量、特征性质、可解释性与计算成本。

## 逐步例子

对表格数据可先用逻辑回归作基线，再训练一棵限制深度的树，检查是否捕捉到非线性阈值。若没有标签，只能先用聚类探索客户群，再由业务人员解释每群含义；不能把聚类编号直接当“真实类别准确率”。对高维特征做 PCA 时，也要只在训练部分拟合主成分。

## 常见误区与自查

树训练分数高容易过拟合；集成不保证总优于良好的基线；无监督结构也可能只是噪声。自查算法输出的语义与任务是否一致。

## 学完后的检验

先合上讲义，自己复述：这个方法解决什么问题、前提是什么、例子中的每一步为何成立、换一组输入时哪些判断必须重做。再完成两道不同的公开练习；练习表现只是初步证据，不能代替真实项目中的实现与复核。
