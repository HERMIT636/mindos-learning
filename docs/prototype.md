# 本地原型运行说明

## 学习流程

1. 配置模型并测试连接。
2. 输入课程名称，可补充希望达到的目标。AI 生成 4—16 个循序渐进的小节目录，目录保存到 SQLite。
3. 进入第一节，点击“生成本节讲解”。讲解保存后可以反复阅读，追问会保留在该节对话里。
4. 点击“生成本节小测”，独立完成 4 道单选题。提交后保存题目、作答、评分与解释，并更新该节的暂定掌握状态。
5. 可以继续测试同一节，或回看已学小节。只有点击“进入下一小节”时课程进度才增加一节；重复请求不会跳过两节。

课程记忆以课程 ID 和浏览器会话隔离。小节状态根据最近两次**已提交**小测得出：低于 60% 为“需补强”；60%—84% 为“正在掌握”；至少两次且最近两次平均达到 85% 才显示“较稳固”。这是便于个人复习的暂定规则，不是经过验证的心理测量或正式考试结果。课程平均正确率只覆盖已测小节，旁边同时显示覆盖率。

## 数据与迁移

默认数据库是 `data/mindos-demo.sqlite3`。旧版数据库首次打开时会先在同目录备份为 `.before-custom-courses.sqlite3`，再删除旧的固定课程学习记录和检索缓存；模型配置仍保留。新表保存课程、目录、讲解、追问、独立小测和作答。未来小节没有讲解和题目，直到学习者主动进入。

本机加密主密钥位于用户目录的 `.config/mindos/master.key`，不会随数据库自动迁移。更换运行环境后如网页显示“需重填密钥”，在模型设置中重新输入即可。前端和模型列表 API 不返回明文密钥。

## 接口

- `GET /api/bootstrap`：模型状态和本会话课程列表。
- `POST /api/courses/create`：用模型规划课程小节并保存。
- `GET /api/course?course_id=...&ordinal=...`：读取已开放小节及课程记忆。
- `POST /api/sections/lesson`、`/api/sections/ask`：生成并保存讲解、追问。
- `POST /api/sections/quiz`、`/api/quizzes/submit`：生成题目、提交并评分。
- `POST /api/sections/advance`：显式推进一节，要求提供当前序号；旧序号重复调用会被拒绝。

所有课程接口按本地浏览器会话筛选。网页只允许访问已经开放的小节；跨会话课程访问会被拒绝。当前无正式账号或多人服务端身份认证，不适合公网或正式学生数据。

## 教学与测评边界

教学提示词要求从零基础出发，逐步解释术语、直觉、例子和误区，并参考**同一课程**已有小节的暂定状态和错题线索。系统不连接网页搜索，也不使用本地 RAG 库。模型可能编造事实、课程顺序或错误答案。单选自动评分采用模型生成的标准答案；如果答案本身有误，掌握状态会被污染。正式试点需要教师审核题库、独立测评和效度检验。
