# Learning Loop P6：上下文感知 AI 导师

P6 是课程中的教学交互层，复用现有课程、知识原子、ATIE、唯一 ModelGateway 与学习闭环。它每次读取当前知识状态后选择讲法，不负责知识认证、评分或自动推进课程。

## 使用方式

进入课程，点击悬浮 AI 图标。可以拖动图标、拖动窗口标题、拖动右下角调整大小；刷新后恢复该课程的位置和尺寸，默认仍折叠。移动端窗口保持在可视区域内。键盘用户可在图标、标题或缩放手柄按 Alt 加方向键移动或调整。

简单概念可只有一段解释；过程用步骤，区别用表格，需要时主动配关系图，数学基础与教学阶段允许时才展开公式或代码。每次讲解都有调整讲法按钮。引导模式一次只问一个问题，定性回应你的解释，再继续追问，不评分。相关知识点可点击回到课程知识星图。

导师的“待验证学习线索”不是已确认误区。点击独立短检测后，通过原有 P0 题目提交保存真实证据。一般题答错可以支持“还需要检查这个知识点”，不能确认导师猜测的某个具体误区；具体误区仍遵循原来的多次独立证据规则。有提示的检测只作练习，可再次独立检测。开放实践和成长路线建议只提供入口，不自动创建任务、重新规划或改变 P1 终局结论。

## 调用与边界

`CourseAssistant → /api/tutor/chat → TutorContextBuilder → LearningStateManager / TeachingOrchestrator / ATIE（只读）→ TutorStrategyEngine / SocraticTutor → ModelGateway → JSON Schema 与范围检查 → ExplanationComposer → TutorMessage / 教学块`。

- `context_id` 是当前课程的选择编号，不是客户端提供的知识状态。每次在服务器检查所有权、开放小节和知识点，重新读取事实。接口不接受客户端掌握率、评分、页面内容或整份模型上下文。
- 模型收到最多 3 个目标知识点与 3 个前置点、相关关系、当前内容片段、最多 6 条同小节相关消息、4 条教学记忆、4 条误区、3 条近期学习事件、一个当前执行摘要及成长目标摘要。整次请求另有 26,000 字符上限。不发送完整课程、所有知识图谱、全部历史或全部执行记录。
- 当前开放任务由服务器识别，省略任务编号不能绕过求助标记。终局题目只读当前有效课程版本。模型看不到正确答案与评分 rubric 的期望答案。求助在模型调用前标记为非独立，即使模型失败也不能消除提示标记。
- 读取 P5 不触发计时、恢复、结束或估时刷新。P6 不调用有刷新/写入行为的 `ContentGenerator.prepare`。
- 新增的提示词在 `prompts/tutor/`：上下文规则、策略、讲解、引导和观察。仍由原 `ModelGateway` 发请求，未创建第二套模型客户端。
- 所有模型结果必须通过 JSON Schema、表格/图示一致性、真实用户引文、课程内 ID、引导深度与既有范围检查。失败只重试一次；仍无效时显示普通文字的明确保守答复，不保存无效输出、候选或学习记忆。普通运行诊断仅记录失败类型/代码，不保存无效原文或完整请求。显式测试诊断文件可以保存已通过验证的合成模型结果。
- 时效问题沿用课程选择的搜索配置。无密钥入口仅覆盖 Wikipedia/GitHub，不是全网搜索；只使用实际标题与短摘要，未阅读全文。失败来源为空并明确保留不确定性。来源偏好不是事实权威，已有冲突保留。

## 数据与有用记忆

四张独立表：`tutor_conversations`、`tutor_messages`、`tutor_memories`、`tutor_observations`。会话以用户/课程唯一隔离，消息拥有 question/explanation/hint/diagnosis/reflection/summary/verification 类型。

寒暄直接临时显示；模型判断与学习无关的聊天也不保存。相关问答每门课程最多保留 200 条，历史每页 80 条。教学记忆最多 40 条，仅接受用户本次原话支持的偏好、明确自述习惯和关键理解；偏好不是 Knowledge Profile，不从时长推断性格或能力。重复原话不重复创建。完整模型上下文不会入库。

观察初始为 `candidate`；`verified` 仅限独立短检测实际支持的知识缺口，不代表具体误区诊断或事实认证；通过检测可 `dismissed`，用户也可忽略。正向理解判断与未能对应具体误区证据的观察仍保留为候选，不用于提升能力。验证任务沿用 P0 quiz，API 以 `concept_check` 描述，不另建评分与任务系统。

软删除保留但禁止访问；恢复保留；课程复制不复制导师记录；永久删除使用外键级联清理。可清除本课程导师对话、偏好和观察，真实学习证据保持。并发重复请求只保存一个问答；清除记忆与问答保存串行处理。

原有 `/api/courses/{id}/assistant/chat`、旧历史和章节追问保留兼容原有集成，P6 前端使用新接口。旧聊天不自动导入 P6 模型历史或教学记忆。图标位置继续复用原 `assistant_position`；窗口尺寸与位置仅保存到浏览器本地的课程键，不包含聊天内容。

## 接口

| 操作 | 接口 | 说明 |
| --- | --- | --- |
| 选择上下文 | GET `/api/tutor/context?course_id=...` | 返回课程选择编号，不保存完整上下文 |
| 提问 | POST `/api/tutor/chat` | `{message, context_id, current_context?, request_id?}`；`current_context` 只能选择小节/原子/已有开放任务 |
| 会话列表 | GET `/api/tutor/conversations` | 返回自己的课程会话 |
| 课程历史 | GET `/api/tutor/conversations?context_id=...&before=...` | 有界分页 |
| 候选观察 | GET `/api/tutor/observations?context_id=...` | 不返回内部置信度 |
| 独立验证 | POST `/api/tutor/observations/{id}/verify` | 空对象；返回已有 P0 检测协议与 `concept_check` 验证任务 |
| 忽略线索 | POST `/api/tutor/observations/{id}/dismiss` | 空对象 |
| 清除导师记忆 | DELETE `/api/tutor/conversations` | `{context_id}`，不删除 P0–P5 数据 |
| 开发记忆 | GET `/api/tutor/memory?context_id=...` | 仅 `MINDOS_DEBUG_LEARNING=1` 开启，仍需课程所有权 |

问题、相关课程内容及最小学习摘要会发送到用户选择的模型服务。密钥仍加密保存，不放入提示词、网页或这些接口。

## 验证与限度

基线 `704e62c`，现有 41 个学习闭环、策略、教学编排文件的 SHA-256 冻结清单在 [冻结记录](learning-loop-p6-frozen.json)，并有自动测试逐一检查。实施前审查见 [审查记录](learning-loop-p6-audit.md)。

最终自动化、浏览器与真模型结果见 [实际验证记录](validation/learning-loop-p6-validation.json)。真模型仅使用临时 Transformer 合成课程，先经原有题目提交生成 QKV 基础证据，再模拟 Q/K 混淆和 Attention 原因提问；检查步骤、对照与单问题引导。个人数据库在验证前后 SHA 不变。有效模型输出保留在 [模型验证记录](validation/learning-loop-p6-real-model.json)。这是有限场景验证，不证明一般教学效果、诊断准确率或事实正确性；教学范围检查仍是启发式。

## 最终自审

| 项目 | 实现与验证 |
| --- | --- |
| 1. 真实学习上下文 | 当前课程/开放小节/原子由服务器读取，有所有权与伪造测试 |
| 2. 无无关全部历史 | 目标/前置优先、同课程同小节有界历史与总请求上限 |
| 3. 动态讲法 | 八种问题策略，ATIE 控制阶段与深度，已有概念证据只减少重复 |
| 4. 自动结构 | 简短段落、步骤、对照、公式、代码、问题及可选图示，安全 DOM 渲染 |
| 5. 苏格拉底 | 一个问题、少量提示，下一轮回应，再引导，不评分 |
| 6. 有价值记忆 | 原话支持和类型门槛，去重、限量、可以清除 |
| 7. 不直接改知识状态 | 问答前后知识状态、证据、策略历史及执行表快照保持 |
| 8. 观察通过验证 | 独立 P0 提交后才支持缺口；一般错误不确认具体误区 |
| 9. 无第二知识状态系统 | 只读原 KnowledgeState；四表仅保存教学互动 |
| 10. 原算法不变 | P0–P5 及既有 ATIE/编排 41 文件 SHA 不变 |
| 11. 不自动推进章节 | API 与浏览器均检查 current_ordinal 不变 |
| 12. 不自动完成任务 | P4/P5 只读摘要和建议入口，无路线/完成写入 |
| 13. 不保存全部聊天 | 寒暄和无关聊天临时显示，不入 P6 对话/记忆 |
| 14. 可拖动 | 图标和窗口标题、边缘吸附、缩放、刷新恢复与键盘支持 |
| 15. 移动端 | 390×844 可视范围与无页面溢出检查、截图 |
| 16. 安全退化 | 结构/范围错误重试一次，再显示明确的无效回答提示；不保存错误原文 |
| 17. AI 判断不当事实 | 观察候选、来源冲突/有限检索说明，诊断仍需证据 |
| 18. 解释不当掌握 | 引导、自述偏好和重要理解不写入学习证据 |
| 19. 候选不当确认 | 无客户端评分/verified 字段；一般题错不确认具体误区 |
| 20. 全部回归 | 最终结果与覆盖记录集中保存在验证 JSON |

P6 完成范围是可运行的教学交互 MVP。启发式策略仍会受问题措辞影响；学习内容与题目需继续教师/真实用户验证。语音、主动提醒和自主改路线未实现。
