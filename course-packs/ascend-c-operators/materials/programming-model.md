# AI Core 编程模型与核函数

本讲义为 MindOS 原创课程草稿，尚待教师审核。先理解现象与条件，再尝试完整例子。

## 为什么要学

Ascend C 让开发者把张量计算映射到 AI Core 上。理解主机和设备的职责、核函数入口以及多核执行方式，才能写出既正确又能扩展到较大输入的算子。

## 核心原理

设备侧核函数负责访问输入输出并执行核心计算，主机侧准备参数并发起调用。多个核实例处理不同的数据区间，需保证索引不重叠、覆盖完整并遵守访存边界。全局内存与片上局部存储用途不同，通常需要显式搬入局部数据、计算后搬出。具体 API 名称、位置枚举和限制随版本查询官方文档。

## 逐步例子

长度 N=1000 的逐元素任务若分给 4 个核，可先按连续区间分配，每核约 250 个元素。写出第 0 核访问 0..249、第 1 核 250..499 等范围，再考虑每核内部按块处理。若分块大小不是 250 的约数，还需一个尾块；不能让最后一核越界读取。

## 常见误区与自查

不要假设核实例之间共享普通局部变量，也不要只验证第一核的输出。自查核编号、块起止索引、覆盖与重叠、全局内存边界。

## 学完后的检验

先合上讲义，自己复述：这个方法解决什么问题、前提是什么、例子中的每一步为何成立、换一组输入时哪些判断必须重做。再完成两道不同的公开练习；练习表现只是初步证据，不能代替真实项目中的实现与复核。
