# 本地学习原型

这是用于大创／挑战杯项目开发和演示的本地预览版，课程内容仍标记为 `draft`。首次进入先选资料模式或大模型模式，然后选课程、章节与目标知识点。界面逐页推进：先做基础测试，完成后自动进入当前知识点讲解，再进入练习与自测，最后查看知识状态和后续计划。顶部步骤导航可在已解锁的功能之间跳转；所有状态都是工程规则的演示结果，不能当作真实学习效果。

## 启动

需要 Python 3.10 或以上版本。从仓库根目录运行：

```bash
python -m mindos.server
```

浏览器打开 <http://127.0.0.1:8765>。默认只监听本机地址 `127.0.0.1`。如需换端口，运行 `python -m mindos.server --port 8766`。使用 `python3` 的环境可相应替换命令。

不配置模型即可用资料模式演示两门课程。它按关键词列出当前课程 Markdown 中的固定讲解与来源片段，并按一级方向、二级线索、三级原文逐步展示；不会对新问题生成个性化解释或新题。服务端配置模型后，用户可选大模型模式：讲解请求包含当前诊断与独立作答状态，模型据此结合检索片段回答疑问；还可分析用户自写的学习目标，将其定位到当前课程的章节和知识点，并按需生成一道练习小测验。模型输出仍可能有错，AI 小测验不计入掌握状态。单选和数值题由服务器按公开课程包中的答案判分。模式、目标、短诊断、作答和向量缓存保存在本地 SQLite `data/mindos-demo.sqlite3`，不会提交到 Git。不同浏览器会话用本地 Cookie 区分，**没有正式账号系统**，因此不要录入真实学生资料。

## 五分钟演示

1. 首次进入选“资料模式”，再进入 Python 基础；选“返回值与屏幕输出”章节中的“返回值”知识点，完成两道基础测试。最后一题提交后会自动进入知识点讲解页。
2. 在讲解页阅读从当前知识点检索出的固定原文，再问“return 和 print 有什么区别？”，切换一级、二级、三级提示并展开出处。没有模型也可完成这一步。
3. 点击“继续：练习与自测”，先做辅助练习，再用另一道公开变式题独立复测。点击“查看证据与后续计划”，观察薄弱点、先修路线与状态更新。
4. 用顶部步骤导航回到知识点讲解或练习页，或者切换线性代数；两门课程的数据和路线彼此隔离。

如已在服务端配置对话模型，可切换“大模型模式”，在目标框输入自己的描述并点击“分析并定位知识点”，确认建议后开始诊断。在资料助手中提问，或点击“生成一道小测验”；小测验的答案会在提交后给出，但不更新知识状态。当前两个示例包只覆盖各自的小范围章节，自定义目标超出课程范围时应改选课程或补充课程包。

短诊断仅给出起点标记，不计入独立掌握证据。辅助练习、同题求助和未自动评分的作答也不会计入。同一题多次提交至多提供一份当前证据。一次独立通过标记为“初步达标”，两道不同题通过标记为“复测通过”；一正一误标记为“待复核”。本地演示中的独立变式仍是公开示例题，不能用于正式效果研究。

## 可选模型与向量检索

把仓库根目录的 `.env.example` 复制为 `.env`，填写你选择的兼容服务的 API 地址、对话模型名称和可选的 Embedding 模型名称，然后**重启本地服务**。远程服务使用 HTTPS；本机服务可使用 HTTP。密钥只放在 `.env`，不要提交到仓库或输入页面。网页只让用户选择是否使用已经配置好的模型，不负责创建模型连接。模型模式下，自定义目标分析、讲解和小测验会向所配置服务发送课程目录、相关资料片段及演示学习状态；请仅用演示数据。

```text
MINDOS_MODEL_BASE_URL=https://api.openai.com/v1
MINDOS_CHAT_MODEL=你已开通的对话模型名称
MINDOS_EMBEDDING_MODEL=你已开通的向量模型名称
MINDOS_MODEL_API_KEY=你的密钥
```

只设置对话模型时，模型模式采用关键词检索后生成带原文入口的讲解；再设置 Embedding 模型时，系统计算课程片段和问题的向量并融合排序。资料模式不会请求对话或向量模型。向量缓存在本地 SQLite 中，缓存键包含模型、课程版本与资料内容。模型讲解连接失败时回到课程原文和关键词检索；自定义目标分析或小测验生成失败时显示错误，不伪装成 AI 结果。模型调用可能产生服务费用；请按服务提供方的政策使用资料。

接口采用 OpenAI 兼容的 [Chat Completions](https://developers.openai.com/api/reference/resources/chat) 与 [Embeddings](https://developers.openai.com/api/reference/resources/embeddings/methods/create) 请求格式。不同兼容服务对模型名称和功能的支持会有差异。本仓库不提供模型密钥，也不默认调用外部服务。

## 当前边界

- 资料只来自当前课程包 `resources` 中的 Markdown；参考答案和评分表不进入资料助手上下文。
- 仅对单选与数值题进行确定性评分；数值题目前要求与示例答案精确相等。简答与代码题不作自动评分，代码不会执行。
- “独立作答”使用公开示例题，答案在仓库里可查，仅供验证产品流程。本地另备未公开的独立测评草案，尚未接入应用，正式试点仍需教师审核与等值性试测。
- 状态规则没有经过教学效度验证；当前尚无正式登录、教师审核页、PostgreSQL / pgvector 部署和真实用户试点。
- AI 目标匹配和临时小测验只覆盖课程包列出的章节与知识点；模型输出需要学习者核对资料，未经教师审核不能用于正式评分。

运行检查：`python -m unittest discover -s tests -v`。课程格式检查仍使用 `python scripts/validate_course_packs.py`，后者需要先安装 `requirements-dev.txt`。
