# 线性回归与逻辑回归

本讲义为 MindOS 原创课程草稿，尚待教师审核。先理解现象与条件，再尝试完整例子。

## 为什么要学

线性模型是理解机器学习的好起点：它把每个特征的贡献组合起来，训练和推断都相对清晰。掌握它之后，才能有依据地判断更复杂模型究竟改进了什么。

## 核心原理

线性回归用输入的加权和预测连续值，可通过最小化平方误差拟合系数；逻辑回归虽然叫“回归”，常用于二分类，它把线性分数经 sigmoid 映射为 0 到 1 的概率，再按分类损失训练。系数大小要结合特征尺度看，相关不等于因果；正则化可抑制过大系数，但强度也要在验证集选择。

## 逐步例子

若线性回归预测 `y=2x+1`，当 x=3 时预测 7，残差是实际值减 7。若二分类模型的线性分数为 0，sigmoid 输出 0.5；这不是“模型一定正确一半”，而是此模型给该类的概率估计。再根据误报与漏报成本选择阈值，而不是机械使用 0.5。

## 常见误区与自查

不要把逻辑回归误当成预测连续目标的普通回归，也不要只凭系数正负宣称因果。自查目标类型、损失函数、预测输出与评价指标是否匹配。

## 学完后的检验

先合上讲义，自己复述：这个方法解决什么问题、前提是什么、例子中的每一步为何成立、换一组输入时哪些判断必须重做。再完成两道不同的公开练习；练习表现只是初步证据，不能代替真实项目中的实现与复核。
