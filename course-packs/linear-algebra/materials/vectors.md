# 二维实向量：有方向和长度的两个分量

本讲义为 MindOS 原创公开教学材料，内容状态：待教师／助教审核。适合熟悉有序数对与基本算术的学习者。

## 为什么用两个数描述一个向量

想象从平面上的一个点先向右走 3 格，再向上走 2 格。把这段位移记为向量 (3, 2)：第一个数描述水平方向的变化，第二个数描述竖直方向的变化。负数表示反方向，例如 (-3, 2) 是向左 3 格、向上 2 格。向量不是单纯的“两个数字凑在一起”；**每个位置有固定含义**，顺序一换，位移通常就变了。

## 从起点和终点读出分量

如果从 A = (1, 1) 走到 B = (4, 3)，位移向量是 B - A = (4 - 1, 3 - 1) = (3, 2)。若换成从 B 回到 A，位移是 A - B = (-3, -2)。这两个向量长度相同、方向相反。

写成 (x, y) 时，`x` 是第一分量，`y` 是第二分量。向量 (2, 5) 与 (5, 2) 一般不是同一个向量；前者水平变化 2、竖直变化 5，后者正好相反。检查向量时不要只看数字是否相同，还要看每个数字所在的位置。

## 点与向量有什么不同

平面上的点 (3, 2) 表示一个**位置**；位移向量 (3, 2) 表示“横向改变 3、纵向改变 2”。数字写法一样，所回答的问题却不同。若从原点出发，向量 (3, 2) 的箭头终点恰好在点 (3, 2)；若从点 (5, 5) 出发，画同一个位移向量，箭头终点会在 (8, 7)。所以一个向量可以平移到不同位置，分量仍相同。

这也解释了为什么求 A 到 B 的位移必须做“终点减起点”。B 的位置本身不告诉你走了多远：从 (0, 0) 到 (4, 3) 是 (4, 3)，从 (1, 1) 到同一个 B 却是 (3, 2)。

## 向量运算为什么可以逐分量进行

两次位移可以接在一起。先走 (2, 1)，再走 (-1, 3)，总位移是 (2 + (-1), 1 + 3) = (1, 4)。这就是向量加法：对应分量相加。

把一次位移放大 2 倍，则 2(2, 1) = (4, 2)；乘以 -1 则得到 (-2, -1)，方向反过来。注意这里的结果仍是**向量**，有两个分量；后面要学习的点积却得到一个**数**。

你可以用箭头检验加法结果：从一个起点画第一支箭头，再从它的终点画第二支箭头；起点到最终终点的箭头就是和向量。如果计算得出的分量与这支箭头的方向相反，通常是减法顺序或某个负号写错了。

## 长度和零向量

向量 (3, 4) 的长度是 5，因为横向和纵向变化构成直角三角形：长度 = √(3² + 4²) = 5。一般地，(x, y) 的长度是 √(x² + y²)。向量 (0, 0) 称为零向量，长度为 0；它与“某一个分量是 0”不同，例如 (0, 4) 的长度仍是 4。

如果坐标单位一致，(0, 4) 表示纯竖直位移，(4, 0) 表示纯水平位移。一个分量为零并不意味着整个向量为零。

## 常见误区与自查

- 把 (2, 5) 与 (5, 2) 当成相同：先分别画出水平和竖直变化，方向就明显不同。
- 把起点坐标误当成位移：位移需要“终点减起点”，例如 A 到 B 是 B - A。
- 把 (0, 4) 叫零向量：只有两个分量都为 0，才是零向量。
- 加法时交叉相加：应当第一分量对第一分量、第二分量对第二分量。

## 试着口头解释

从 (2, -1) 到 (5, 1) 的位移是什么？先算终点减起点，得到 (3, 2)。再想：从 (5, 1) 返回 (2, -1) 应该是 (-3, -2)。如果你能把正负号解释成方向变化，而不只是机械计算，就具备学习点积的基础。
