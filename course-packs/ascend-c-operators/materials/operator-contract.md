# 算子数学定义与输入输出契约

本讲义为 MindOS 原创课程草稿，尚待教师审核。先理解现象与条件，再尝试完整例子。

## 为什么要学

算子赛第一步不是写核函数，而是把题目转成可验证的计算契约。公式、形状、数据类型、布局、广播、边界和误差标准若有一项理解错，即使代码很快也不算正确。

## 核心原理

先写纯数学或 CPU 参考实现，列出每个输入的 shape、dtype、取值范围和输出约束。区分逐元素、归约、矩阵类与变形类算子，因为它们的数据依赖和并行分块方式不同。确认是否允许就地写入、是否有动态形状、输出要按什么容差比对；题目规定优先于通用经验。

## 逐步例子

以逐元素 Add 为例，若两个长度为 N 的张量形状相同，结果第 i 项为 `x[i]+y[i]`。先确认 N=0 或不能整除块长时如何处理、是否支持 fp16 与 fp32、输出是否允许和输入别名。用小尺寸手算例子与 CPU 参考结果一致后，再设计核函数；不要从某个示例代码反推正式题意。

## 常见误区与自查

最常见错误是把样例形状当作全部形状，或忽略负数、非整块尾部和 dtype 转换。自查一张契约表：输入、输出、形状、精度、边界、判分口径。

## 学完后的检验

先合上讲义，自己复述：这个方法解决什么问题、前提是什么、例子中的每一步为何成立、换一组输入时哪些判断必须重做。再完成两道不同的公开练习；练习表现只是初步证据，不能代替真实项目中的实现与复核。
