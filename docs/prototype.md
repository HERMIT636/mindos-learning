# 本地学习原型

这是用于大创／挑战杯项目开发和演示的本地预览版，课程内容仍标记为 `draft`。网页教学需要先配置对话模型，再选课程、带编号的章节与目标知识点。界面逐页推进：学前小测可做可跳过，随后从目标路线的第一讲逐步学到目标；每节可随时追问、做即时小测，再进入独立复测与后续计划。顶部步骤导航可在已解锁的功能之间跳转；所有状态都是工程规则的演示结果，不能当作真实学习效果。

## 启动

需要 Python 3.10 或以上版本。从仓库根目录运行：

```bash
python -m pip install -r requirements.txt
python -m mindos.server
```

浏览器打开 <http://127.0.0.1:8765>。默认只监听本机地址 `127.0.0.1`。如需换端口，运行 `python -m mindos.server --port 8766`。使用 `python3` 的环境可相应替换命令。

机器学习、HPC 与 Ascend C 为主路线，Python 和线性代数是可选先修。AI 逐节讲解使用当前课程、知识点、直接先修与诊断／独立作答状态，不把旧本地讲义作为主稿。每节生成一次讲解并保存于本机会话；追问会带上本节讲解和近期对话，刷新页面后可继续。节后小测依据本节 AI 讲解生成，答后给解释，但不计入掌握状态。单选和数值独立题由服务器按公开课程包中的答案判分。目标、跳过状态、短诊断、作答和教学对话保存在本地 SQLite `data/mindos-demo.sqlite3`，不会提交到 Git。不同浏览器会话用本地 Cookie 区分，**没有正式账号系统**，因此不要录入真实学生资料。

## 五分钟演示

1. 打开网页中的“管理模型与 API”，填写服务地址、对话模型名称及密钥并测试连接；进入“机器学习”，选第 1 章“问题与数据”中的“任务类型与基线”，点击“跳过测验，从零开始讲解”。
2. 阅读 AI 的完整讲解，遇到不懂的步骤随时提问，也可以输入“继续”；讲完点击“开始本节小测”，提交后查看解释，再进入下一讲。
3. 点击“继续：练习与独立自测”，先做辅助练习，再用另一道公开变式题独立复测。点击“查看证据与后续计划”，观察薄弱点、先修路线与状态更新。
4. 用顶部步骤导航回到知识点讲解或练习页，或者切换 HPC、昇腾 Ascend C；五门课程的数据和路线彼此隔离。

在目标框输入自己的描述可让 AI 对照课程目录定位知识点。三门主路线课程已按章节覆盖基础路径，但教学输出仍可能不准确；自定义目标超出当前知识点目录时应改选课程或补充课程包。当前模型响应不是流式输出，完整回复生成后一次显示。

跳过学前小测不会记为答错或伪造诊断结果。短诊断仅给出起点标记，不计入独立掌握证据。辅助练习、同题求助和未自动评分的作答也不会计入。同一题多次提交至多提供一份当前证据。一次独立通过标记为“初步达标”，两道不同题通过标记为“复测通过”；一正一误标记为“待复核”。本地演示中的独立变式仍是公开示例题，不能用于正式效果研究。

## 模型配置

推荐在网页的“管理模型与 API”中添加配置：填写配置名称、兼容服务 API 地址、对话模型名称和密钥；向量模型名称可留空。可保存多个配置、切换、测试和删除。密钥输入框始终不回显；修改配置时留空表示保留原密钥，也可勾选清除。远程服务必须使用 HTTPS，本机模型可使用 HTTP。每个浏览器会话分别选择当前模型；配置本身保存在这台电脑，尚无正式账号隔离。讲解、追问和小测会向选用的模型服务发送课程目标、学习状态以及本节近期对话；请仅用演示数据。

密钥以 Fernet 加密后存入本地 SQLite；解密主密钥默认保存在当前操作系统用户目录的 `~/.config/mindos/master.key`，与项目数据库分开，程序在支持权限位的系统上要求仅本人可读写。网页与配置列表只显示是否已设置密钥。备份或迁移时须同时妥善保存主密钥；丢失后旧密钥无法解密，需要重新填写。这个本机原型没有多用户登录，不适合共享电脑上存放多人付费 API 密钥。加密保护数据库副本泄露时的密钥内容，不能抵御已经控制本机账户的程序。

原有 `.env` 配置仍可作为兼容选项，需重启服务后生效；不要把 `.env` 提交到仓库：

```text
MINDOS_MODEL_BASE_URL=https://api.openai.com/v1
MINDOS_CHAT_MODEL=你已开通的对话模型名称
MINDOS_EMBEDDING_MODEL=你已开通的向量模型名称
MINDOS_MODEL_API_KEY=你的密钥
```

新的教学页面不使用外部资料检索或旧本地讲义作主讲。提示词规定零基础起点、术语白话解释、逐步例子、追问时承接上下文，以及版本／接口不确定时明确说明。没有实时联网搜索；涉及 Ascend C 等版本敏感知识时需要另核官方文档。模型连接失败时页面显示错误，不会假装给出 AI 讲解。原来的资料问答与 Embedding 检索代码暂保留供研究，未在新的教学页面使用。AI 小测依据本节生成讲解出题，未经教师审核，不能当正式测评；模型调用可能产生费用。

接口采用 OpenAI 兼容的 [Chat Completions](https://developers.openai.com/api/reference/resources/chat) 与 [Embeddings](https://developers.openai.com/api/reference/resources/embeddings/methods/create) 请求格式。不同兼容服务对模型名称和功能的支持会有差异。本仓库不提供模型密钥，也不默认调用外部服务。

## 当前边界

- 网页教学使用 AI 生成的逐节讲解和对话；旧本地讲义及外部导读未删除，但不进入此教学流程。参考答案和评分表不进入 AI 教师上下文。
- 仅对单选与数值题进行确定性评分；数值题目前要求与示例答案精确相等。简答与代码题不作自动评分，代码不会执行。
- “独立作答”使用公开示例题，答案在仓库里可查，仅供验证产品流程。本地另备未公开的独立测评草案，尚未接入应用，正式试点仍需教师审核与等值性试测。
- 状态规则没有经过教学效度验证；当前尚无正式登录、教师审核页、PostgreSQL / pgvector 部署和真实用户试点。
- AI 目标匹配和临时小测验只覆盖课程包列出的章节与知识点；模型输出需要学习者核对资料，未经教师审核不能用于正式评分。

运行检查：`python -m unittest discover -s tests -v`。课程格式检查仍使用 `python scripts/validate_course_packs.py`，后者需要先安装 `requirements-dev.txt`。
